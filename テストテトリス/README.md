# テストテトリス

ブラウザで遊べる、非公式の学習用ブロックゲームです。外部ライブラリやインストールは不要です。

## 遊び方

リポジトリの「Code → Download ZIP」でダウンロードして展開し、このフォルダーの `index.html` をブラウザで開いてください。

- 左右キー：移動
- 上キー：回転
- 下キー：下に移動
- スペース：一気に落とす
- P：一時停止・再開
- スマホ：画面下の操作ボタン

横一列をそろえると消えます。10ラインごとにレベルが上がり、落下速度が上がります。次のブロックと着地位置のガイドも表示します。

## 編集

画面・デザイン・動作は `index.html` にまとめています。Codexにこのリポジトリを指定して変更を依頼できます。
